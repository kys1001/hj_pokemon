# ⚡ 포켓 단어 배틀 (HJ Pokémon Word Battle)

아이패드 카메라로 단어를 촬영하면 글자를 인식해 나만의 단어장을 만들고, 포켓몬 배틀 스타일로 즐기는 영단어 퀴즈 게임입니다.

## 🎮 게임 모드 (3가지)
- ⌨️ **단어 → 스펠링 입력** : 뜻을 보고 영단어를 직접 타이핑
- 🔤 **영어 → 뜻 맞히기** : 영단어를 보고 4지선다로 뜻 선택
- 💬 **뜻 → 영단어 맞히기** : 한글 뜻을 보고 4지선다로 영단어 선택

## 🌟 난이도 (3단계)
- ⭐ 초급 / ⭐⭐ 중급 / ⭐⭐⭐ 고급 (각 20단어)

## 📸 촬영 기능
아이패드 카메라로 영단어를 찍으면 **글자 인식(OCR)** 으로 단어를 뽑아내고, 뜻을 입력해 나만의 단어장에 저장합니다. (브라우저 localStorage에 자동 보관)

## ▶️ 플레이 방법
GitHub Pages 주소를 아이패드 사파리로 열면 바로 실행됩니다. 설치 불필요.

## 🛠 기술
- 순수 HTML / CSS / JavaScript (단일 파일)
- 글자 인식: [Tesseract.js](https://tesseract.projectnaptha.com/)
- 효과음: Web Audio API
